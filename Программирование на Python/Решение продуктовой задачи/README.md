# Решение продуктовой задачи

### Анализ транзакций розничного магазина

В этом проекте я исследую данные о покупках и пользовательских операциях: очищаю транзакции, нахожу активных покупателей, оцениваю популярность товаров и выручку заказов, а затем проверяю корректность временных метрик. Работа выполнена в Jupyter Notebook на Python.

## Задачи и подход

| Этап | Что сделано |
| --- | --- |
| Подготовка данных | Загрузка CSV из ZIP с кодировкой `ISO-8859-1`, поиск и удаление полных дубликатов, исключение отменённых транзакций с префиксом `C` в `InvoiceNo` |
| Сегмент покупателей | Подсчёт уникальных заказов клиентов из Германии и выделение клиентов выше 80-го процентиля |
| Товары и выручка | Поиск наиболее часто встречающихся кодов товаров и расчёт выручки заказа как суммы `Quantity × UnitPrice` по его строкам |
| Операции пользователей | Анализ статусов, подсчёт успешных операций по пользователям и построение графиков распределения |
| Проверка временной метрики | Сводная таблица операций по пользователям и минутам; исправление признака минуты: `час × 60 + минута` |

## Основные результаты

- В исходной таблице **541 909 строк**; найдено **5 268 полных дубликатов**.
- После удаления дубликатов выявлена **9 251 строка отменённых транзакций**.
- Для покупателей из Германии 80-й процентиль числа уникальных заказов равен **7**; для анализа выбраны клиенты с большим числом заказов.
- Среди их покупок после исключения кода доставки `POST` чаще всего встречается товар **`22326`**.
- Пять крупнейших заказов по рассчитанной выручке: **`581483`, `541431`, `574941`, `576365`, `556444`**.
- В данных об операциях пользователей, показанных в ноутбуке, **3 692** успешных операций, **1 619** отменённых и **4** ошибки. Среднее число успешных операций на пользователя — около **66**.
- Исходный столбец `minute` содержит лишь минутную часть времени (0–59). Для оценки активности в течение дня используется `true_minute` с учётом часа.

Числа выше отражают расчёты и сохранённые результаты в ноутбуке.

## Файлы

- [`solving_product_problems_Homework.ipynb`](solving_product_problems_Homework.ipynb) — код, пояснения, таблицы и графики.
- [`trans_data.zip`](trans_data.zip) — архив с `data.csv` для первой части (поля заказа, товара, количества, цены, клиента и страны).
- [`transaction_data.csv`](transaction_data.csv) — операции пользователей для второй части.
- [`transaction_data_updated.csv`](transaction_data_updated.csv) — те же операции с добавленным полем `minute` для проверки временной метрики.

## Как запустить

1. Установить Python и Jupyter Notebook, затем зависимости: `pip install pandas seaborn matplotlib notebook`.
2. Открыть ноутбук из этой папки. Для первой части достаточно расположенного рядом `trans_data.zip`.
3. Выполнить ячейки по порядку: все три файла данных находятся рядом с ноутбуком.

Ноутбук содержит сохранённые выводы, поэтому с ходом анализа можно ознакомиться и без запуска.
