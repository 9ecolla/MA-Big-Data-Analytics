# Анализ цен на авокадо

### Оконные функции и интерактивная графика · Python

Как меняется средняя цена авокадо со временем и что помогает увидеть за недельными колебаниями? В этом учебном проекте я агрегирую данные по датам, сравниваю способы сглаживания временного ряда и отдельно исследую цены на органическое авокадо в Чикаго. Результаты представлены в таблицах, статических графиках и интерактивном графике.

## Задача

Изучить динамику средней цены и применить несколько приёмов анализа временного ряда:

1. Рассчитать среднюю цену для каждой даты без деления по регионам и типам авокадо.
2. Найти трёхнедельное скользящее среднее и сравнить графики с окнами **2, 4, 10 и 50 наблюдений**.
3. Рассчитать экспоненциальное скользящее среднее с `span=2`.
4. Для органического авокадо в Чикаго построить интерактивный график четырёхнедельного скользящего среднего.
5. Разделить цены в Чикаго на две категории относительно их среднего значения и сравнить число наблюдений.

Здесь одна дата соответствует **неделе**, поэтому окно из четырёх наблюдений охватывает четыре последовательные недели, а не четыре дня. Средняя цена по дате — обычное среднее по строкам датасета, **без взвешивания по объёму продаж**.

## Данные

Источник, указанный в задании, — **Hass Avocado Board**. Приложенный [`avocado_full.csv`](avocado_full.csv) содержит **18 249 строк и 13 столбцов** без пропусков. Период: **4 января 2015 — 25 марта 2018 года**, 169 уникальных недель, 54 региона и два типа авокадо (`conventional` и `organic`).

| Поле | Содержание |
| --- | --- |
| `Date` | Дата недельного наблюдения |
| `AveragePrice` | Средняя цена одного авокадо |
| `Total Volume` | Общий объём продаж |
| `4046`, `4225`, `4770` | Продажи авокадо с соответствующим кодом PLU |
| `Total Bags`, `Small Bags`, `Large Bags`, `XLarge Bags` | Количество упаковок всего и по размеру |
| `type`, `year`, `region` | Тип авокадо, год и регион |

## Что сделано

| Этап | Метод | Результат |
| --- | --- | --- |
| Агрегация | `groupby('Date')` и среднее `AveragePrice` | Временной ряд из 169 недель; первая средняя цена — **1,301296…** за 04.01.2015 |
| Скользящее среднее | `rolling(3).mean()` | Максимальное значение после округления — **1,85** |
| Сравнение окон | `rolling()` для 2, 4, 10 и 50 наблюдений; `seaborn` и `matplotlib` | Более широкое окно сильнее сглаживает краткосрочные колебания, но медленнее отражает изменения |
| Экспоненциальное сглаживание | `ewm(span=2).mean()` | Получен ряд, в котором недавним значениям отведён больший вес |
| Анализ Чикаго | Фильтр `region == 'Chicago'` и `type == 'organic'`, `rolling(4).mean()`, `plotly.express` | Интерактивный график для 169 недель; значения за **21.08.2016 — 2,102** и **19.02.2017 — 1,533** |
| Группировка цен | `pd.cut()` относительно среднего для Чикаго | **95** наблюдений с ценой не выше среднего и **74** — выше среднего |

Средняя цена органического авокадо в Чикаго равна **1,744201…**. Значения для двух отдельных дат выше относятся к четырёхнедельному скользящему среднему и округлены до трёх знаков, как в ноутбуке.

## Как запустить

1. Установите Python и Jupyter Notebook, затем зависимости:

   ```bash
   pip install notebook pandas matplotlib seaborn plotly
   ```

2. Запустите Jupyter **из папки проекта** и откройте ноутбук:

   ```bash
   jupyter notebook window_functions_and_interactive_graphics_Homework.ipynb
   ```

3. Выполните ячейки по порядку. Другие датасеты для этого проекта не нужны.

В ноутбуке сохранены результаты выполнения. Для интерактивного графика удобнее открыть его в Jupyter или Colab: статический просмотр на GitHub может не воспроизводить интерактивность. При запуске в Colab загрузите `avocado_full.csv` в текущую рабочую папку сеанса.

## Вывод

Оконные функции делают общий тренд заметнее на фоне недельных изменений цен. Размер окна определяет баланс между плавностью графика и чувствительностью к новым значениям. В выбранном сегменте Чикаго цены на органическое авокадо чаще находятся **на уровне среднего или ниже него** (95 против 74 наблюдений).
